A plugin for nvim to suspend languge server protocol client when idle or unfocus nvim.

## Build Instructions

To build the project from source, follow these steps:

1. Clone the repository:

   ```shell
   git clone https://github.com/Akazukin-Team/lsp-suspend.nvim.git
   cd lsp-suspend.nvim
   ```

2. Build the project with Shell:

   ```shell
   sh build.sh
   ```

   The compiled Lua file will be located in the `out/` directory.
